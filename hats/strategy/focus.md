# Focus: what should be cut so the rest can work?

Assume the plan tries to do too much. Look for:

- More bets than the team can run properly at once. Say which one to keep if only one were allowed, and why.
- Work that does not serve the stated number.
- Bets that only pay off after another one succeeds, running in parallel with it.
- New channels, segments or products when the existing one is not yet working.
- No "not doing" list, or one that names nothing anybody wanted to do.

For each cut, say what is lost and why that is acceptable now.
