# Claims check: is every claim true and sourced?

Go through each factual claim in the plan and try to trace it. Look for:

- Product claims that the code or docs in this directory do not support. Open the files.
- Numbers, comparisons and "best / first / only" statements with no source.
- Claims about competitors or the market that would not survive being checked.
- Anything that breaks the rules files in this directory (tone, wording limits, things that must not be said).

Quote the claim, then say what you found when you checked it.
